# Personal portfolio

A responsive single-page portfolio in plain HTML, CSS and a small amount of JavaScript. No installation, build step, external fonts or image downloads.

## Preview

Keep `index.html`, `styles.css` and `script.js` together and open `index.html` in a browser.

## Personalise

- The name (Joey Yong) and email are already filled in. Update them in `index.html` if they change.
- In the **Let's connect** section, the email button uses his address; replace the placeholder "Portfolio / Instagram" link (`href="#"`) with a real link, or delete it.
- The four short descriptions under **Dental practice** are generic wording; edit them to his own.
- Colours live in the `:root` block at the top of `styles.css`.
- Primary-school dates are kept as supplied (1992–2004). Please double-check before publishing.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css` and `script.js` to the repository root.
3. In **Settings → Pages**, deploy from a branch, choose `main` and the root folder, then save.
4. Open the URL shown in the Pages settings once deployment finishes.

## What's included

Sticky header with mobile menu and active-section highlighting, scroll-reveal animations, contact section, larger and more readable text, favicon and social-share tags, keyboard focus styles, skip link, reduced-motion support (animations switch off for people who request it), print styles, and an expandable introduction using the native `details` element.
